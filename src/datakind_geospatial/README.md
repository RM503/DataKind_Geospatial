# datakind_geospatial

This package contains the Kedro project entrypoint, settings, pipeline registry, and Kedro-managed pipelines.

Pipeline documentation lives in [pipelines/README.md](/Users/rafidmahbub/Desktop/DataKind_Geospatial/src/datakind_geospatial/pipelines/README.md).

Useful commands:

```bash
uv run datakind-geospatial registry list
uv run datakind-geospatial run
uv run datakind-geospatial run --pipeline vi_preprocessing
uv run datakind-geospatial run --pipeline classification_training
uv run kedro viz
```
